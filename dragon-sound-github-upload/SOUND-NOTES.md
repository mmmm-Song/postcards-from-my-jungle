# Dragon sounds

This sound portion contains 16 generated WAV files, `sound-generation.ipynb`, and `sound-generation-log.json`.

- Model: [Stable Audio Open 1.0](https://huggingface.co/stabilityai/stable-audio-open-1.0).
- Format: 44,100 Hz, stereo, 16-bit PCM WAV.
- Durations: 3 to 10.5 seconds, increasing by 0.5 seconds.
- Generation: 100 diffusion inference steps, a distinct seed and prompt for every file.
- The log records the exact saved prompts, seeds and requested/saved durations.

The notebook was aligned with the downloaded generation log after generation; it contains no reconstructed execution outputs. Original Colab library versions were not recorded. Model sampling and library changes may prevent bit-for-bit reproduction.
